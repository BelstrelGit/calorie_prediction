# calorie_prediction

## Проект модуля. Нейросеть для предсказания калорийности блюд

Цель: построить DL-модель, которая по фотографии блюда, списку ингредиентов и массе порции предсказывает общую калорийность.

Целевая метрика: **MAE < 50** на тестовой выборке.

В проекте используется мультимодальная архитектура:

- текст ингредиентов → BERT;
- изображение → EfficientNet-B0;
- масса порции → числовой признак;
- объединённые признаки → regression head с одним выходом.

## Подготовка окружения

Для финального запуска в Google Colab используется GPU-runtime **Tesla T4**.

Перед запуском notebook необходимо загрузить в `/content`:

- `nutrition.zip` — архив с датасетом;
- `calorie_prediction-main.zip` — архив репозитория.
